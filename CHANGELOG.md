## 0.5.1

- Add `protoc_plugin_parameters` option to pass custom parameters to the Dart
  protoc plugin (thank you to [fischerscode](https://github.com/fischerscode)!)

## 0.5.0

- Support `protoc_plugin` versions 23.0.0 and newer, which use pub workspaces
  (thank you to [SynSzakala](https://github.com/SynSzakala) and
  [quaaantumdev](https://github.com/quaaantumdev)!)
- Allow `build` 3.x and 4.x as well as `archive` 4.x, so the package can be used
  together with the current `build_runner` without `dependency_overrides`
- Bump the default `protobuf_version` to `36.1` and the default
  `protoc_plugin_version` to `25.0.0`. Note that code generated by
  `protoc_plugin` 25.0.0 requires `protobuf: ^6.0.0` in your project, and
  compiling the plugin requires Dart SDK 3.7.0 or newer. Pin
  `protoc_plugin_version` in your `build.yaml` if you need to stay on an older
  version.
- Require Dart SDK 3.0.0 or newer
